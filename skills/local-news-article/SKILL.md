# 지역신문 기사 작성 스킬

## 절대 원칙 — 원문에 없는 사실은 쓰지 않는다

이 스킬은 **주어진 자료를 기사 형식으로 재구성**하는 것이지 취재하는 것이 아니다.
기사에 들어가는 모든 사실은 사용자가 준 원문에서 확인돼야 한다.

지역신문은 독자가 기사 속 장소·사람·사건을 직접 아는 매체다. 지어낸 한 줄이 실존 인물의
발언으로, 실제 예산으로, 확정된 계획으로 읽힌다. 틀리면 바로 들킨다.

**만들어내면 안 되는 것:**

| 항목 | 원문에 없을 때 |
|------|----------------|
| 발언·코멘트 (기관장·담당자·주민) | 큰따옴표를 비워두고 자리만 표시 |
| 수치 (예산·면적·인원·기간) | 쓰지 않는다. 어림수로 바꾸지도 않는다 |
| 인명·직책·기관명 | 쓰지 않는다 |
| 날짜·일정 | 쓰지 않는다 |
| 사업 배경·추진 이유 | 추측하지 않는다 |
| 현장 분위기·참석자 반응 | 묘사하지 않는다 |
| 향후 계획·기대 효과 | 원문에 명시된 것만 |

**빈 자리는 이렇게 표시한다:**

```
[관계자 코멘트 필요 — 확보 후 삽입]
[사업비 확인 필요]
[개소식 일자 확인 필요]
```

기사가 짧고 밋밋해지는 편이 낫다. 출력 마지막에 **무엇이 비었는지 목록으로 알린다.**

원문에 있는 사실도 추론으로 늘리지 않는다. "예산 28억"에서 "대규모 투자"는 해석이지만,
"3년에 걸친 준비 끝에"는 원문에 없으면 창작이다.

## 지역신문 기사의 핵심 원칙

지역신문 기사는 전국지와 다르다. 독자가 그 지역에 살고, 기사 속 장소·사람·사건을 직접 아는 경우가 많다. 따라서 세 가지를 균형 있게 담아야 한다:

- **정보(Information)**: 6하원칙 기반의 정확한 사실. 수치, 일정, 담당자 명확히.
- **공감(Empathy)**: 지역 주민의 일상과 연결되는 시선. "우리 동네 이야기"처럼 읽혀야 함.
- **감동(Emotion)**: 사람 중심 서사. 원문에 있는 코멘트와 반응을 살리고, 변화의 의미를 짚는다.
  감동은 없는 말을 지어내서가 아니라 있는 사실을 잘 배치해서 만든다.

## 기사 구조 (다이아몬드형 권장)

지역 기사는 역피라미드(팩트 우선)와 피라미드(감동 마무리)를 결합한 **다이아몬드형**이 효과적이다.

```
[제목]     - 핵심 사실 + 의미/기대감 담은 큰따옴표 부제 선택 가능
[리드]     - 1~2문장. 6하원칙 요약. 독자 관심 즉시 포착.
[핵심사실] - 사업 규모, 일정, 주체 등 구체적 정보. 원문의 수치 그대로.
[배경/맥락]- 원문이 밝힌 추진 배경만. 원문에 없으면 이 블록을 생략한다.
[현장/인물]- 원문에 행사 묘사가 있을 때만. 분위기를 지어내지 않는다.
[관계자 코멘트] - 기관장·담당자 발언. 직접 인용("  "처리). 원문에 있을 때만.
[주민 반응] - 실제 수혜자·주민의 목소리. 원문에 있을 때만. 없으면 생략한다.
[향후 계획] - 원문에 명시된 계획만. 없으면 핵심사실로 담백하게 끝낸다.

**블록은 채워야 할 칸이 아니라 원문에 재료가 있을 때 쓰는 서랍이다.**
8개를 다 채운 기사보다 4개로 정확한 기사가 낫다.
```

## 문체 가이드

### 해야 할 것
- 문장은 단문 위주. 한 문장 = 한 생각.
- 수치는 아라비아 숫자 + 한글 단위. (예: 28억 5,700만 원 / 975㎡)
- 인명 표기: 소속·직책 앞에 이름. (예: 최종길 관장)
- 인용문은 큰따옴표. 마지막에 `~고 밝혔다 / ~고 말했다 / ~며 기대감을 나타냈다` 처리.
  큰따옴표 안은 원문 발언 그대로. 서술 동사만 문맥에 맞게 고른다.
- 리드에 가장 강한 정보 or 가장 공감 가는 장면 배치.
- 마지막 문단: 원문에 향후 계획이나 기대 효과가 있으면 그것으로 마무리.
  없으면 억지 전망을 붙이지 말고 핵심 사실로 담백하게 끝낸다.

### 하지 말아야 할 것
- **원문에 없는 사실 추가** (수치·발언·배경·분위기 — 그럴듯해도 창작이다)
- 감상적 수식어 남발 ("새롭게 거듭난", "소중한 발걸음" 남발 금지)
- 보도자료 원문 그대로 복붙
- 같은 표현 반복 (관장→최 관장→최종길 관장 교차 사용)
- 문장 첫 글자 "이", "또한", "한편" 연속 반복

## 제목 작성법

```
기본형: [주체], [행위]…[의미/기대]
예: ○○도서관, 보존서고 증축 완료…지역 기록 보존 기반 강화

부제 활용 (필요시):
큰따옴표 안에 관계자 발언 핵심 한 줄
예: "단순 공간 확장 아닌 미래 세대를 위한 준비"
```

## 인터뷰 코멘트 처리

- **기관장/담당자**: 사업의 의미와 향후 방향. 공식적이되 진정성 있게.
- **주민/수혜자**: 실생활 변화, 기대감, 감사. 구어체 가깝게.
  익명 표기("참석 주민", "지역 주민 A씨")는 **원문에 발언이 있으나 이름만 없을 때** 쓴다.
  발언 자체가 없을 때 익명으로 지어내는 용도가 아니다.

**인용 처리 형식** (문장 골격만 참고 — 아래 발언은 실제 발언이 아닌 형식 예시다):

```
[성명] [직책]은 "[사업의 의미 한 문장]"이라며 "[향후 방향 한 문장]"고 밝혔다.

[행사]에 참석한 한 주민은 "[실생활 변화 한 문장]"이라며 기대감을 나타냈다.
```

**인용문은 반드시 원문에 있는 발언만 사용한다.** 원문에 코멘트가 없으면 지어내지 말고,
"관계자 코멘트 필요 — 확보 후 삽입" 이라고 표시한 자리를 남긴다.

## 글자 수 기준

| 유형 | 분량 |
|------|------|
| 단신 | 200~400자 |
| 일반 기사 | 600~900자 |
| 기획/심층 | 1,000자 이상 |

사용자가 분량을 지정하지 않으면 원문 분량과 비슷하게 유지한다.

## 작업 흐름

1. 원문(보도자료·메모·텍스트)에서 6하원칙 추출
2. 핵심 팩트 → 배경 → 현장 → 코멘트 → 전망 순 재구성
3. 제목 작성 (메인 + 필요시 부제)
4. 문체 교정: 수식어 정리, 반복 제거, 문장 단문화
5. 인용문 정리 — 군더더기·중복 삭제까지만. 표현을 바꾸거나 문장을 보태지 않는다
6. 마무리: 향후 계획 or 기대감 문장으로 종결
