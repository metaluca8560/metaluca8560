## 2부. Fable 5 전문가 컨설팅

### A. 지금 당장 고쳐야 할 것 (보안 · 우선순위 최상)

1. **`api/proxy.js`가 열려 있음.** `Access-Control-Allow-Origin: *` 에 출처 확인·사용량 제한이 없어서,
   배포 주소를 아는 누구나 **당신의 Claude API 키로 무제한 호출**을 할 수 있습니다. 최소 조치:
   - 허용 출처를 본인 도메인으로 제한 (`Access-Control-Allow-Origin`을 특정 도메인으로)
   - `Origin`/`Referer` 검사 + 요청당 `max_tokens` 상한 유지 + Vercel 방화벽 또는 간단한 요청 횟수 제한
2. **n8n 웹훅 URL이 HTML에 그대로 노출됨** (`youtube-analyzer.html`). 스팸 호출로 Slack/Discord 채널이 오염될 수 있으니, 웹훅도 프록시 뒤로 옮기거나 n8n 쪽에서 시크릿 헤더 검증을 켜세요.

### B. 우선순위 매트릭스

| 아이디어 | 사업 기여 | 노력 | 판정 |
|---|---|---|---|
| ① 랜딩 리드 폼 + 카카오 연결 완성 | 매우 높음 (매출 직결) | 낮음 (설정만 남음) | **1순위 — 이번 주에 끝내기** |
| ② 숏폼 분석기 3종 → 통합 대시보드 | 높음 (매일 쓰는 도구 + 강의 소재) | 중간 | **2순위 — 다음 빌드 대상** |
| ⑥ n8n 자동화 확장 | 중간 (②에 종속) | 낮음 | ②와 함께 진행 |
| ③ 메디컬 앱 + MedInfo MCP 연동 | 중간 (포트폴리오 대표작 가능) | 중간 | 3순위 |

| ⑦ 미니 앱 실험 | 낮음 | 낮음 | 여가 시간에 |

### C. 2순위 상세 설계 — "숏폼 트렌드 통합 대시보드" MVP 스펙

현재 3개 분석기는 코드의 70~80%가 중복입니다(동일한 프록시 호출, 유사한 폼/결과 카드). 통합 시:

- **구조**: `shortform/index.html` 단일 앱, 상단 탭으로 YouTube/TikTok/Reels 전환. 공통 로직(`proxy 호출`, `결과 카드 렌더링`, `n8n 알림`)은 `shortform/core.js` 하나로.
- **저장**: 분석 결과를 `localStorage`에 이력으로 쌓고 "지난 분석 다시 보기" 제공 → 트렌드 변화를 시계열로 비교 가능.
- **자동화**: n8n 워크플로우를 "주 1회 지정 키워드 자동 분석 → 카톡/Slack 요약" 크론으로 승격. 지금 가진 재료(웹훅 + proxy)로 바로 가능.
- **확장(선택)**: 네이버 데이터랩 MCP로 국내 검색 트렌드를 결과에 병기 → 국내 시장용 차별점.
- **효과**: 유지보수 파일 3→1개, 새 플랫폼 추가 비용 급감, "내가 만든 도구로 콘텐츠 기획한다"는 강의 소재 완성.

### D. 1순위 체크리스트 (설정만 하면 끝나는 것들)

- [ ] Formspree 폼 생성 → `script.js`의 `FORM_ENDPOINT`에 붙여넣기 (README에 이미 절차 있음)
- [ ] 카카오톡 채널 ID → `script.js`의 `KAKAO_CHANNEL_ID`에 입력
