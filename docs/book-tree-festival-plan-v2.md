# 📚 북트리(Book Tree) 페스티벌 — 기획안 v2.0

> **"책 읽으러 오지 마. 놀러 와."**
> 독서 행사가 아니라, 책을 소재로 한 **청소년 놀이터**를 만듭니다.

---

## 0. 재구성 방향 (v1 → v2 무엇이 달라졌나)

| 구분 | 기존 (v1) | 재구성 (v2) |
|---|---|---|
| 정체성 | 독서 문화 행사 | **책 소재의 팝업 페스티벌** (팝업스토어 감성) |
| 참여 방식 | 프로그램 나열형 | **스토리·미션 기반 동선 설계** (게이미피케이션) |
| 리워드 | 스탬프 완주 시 굿즈 | **레벨업형 리워드 + 실시간 랭킹 + 한정판 굿즈** |
| 홍보 | 포스터·SNS 일반 홍보 | **숏폼 챌린지 + 또래 크루 + "가서 찍을 것"이 있는 공간** |
| 운영 주체 | 주최 측 중심 | **청소년 크루가 기획·운영의 절반을 담당** |

**핵심 원칙 3가지**
1. **찍을 게 있어야 온다** — 모든 존(Zone)에 포토 포인트 1개 이상 설계
2. **할 게 있어야 남는다** — 관람형 0%, 전 프로그램 체험형
3. **자랑할 게 있어야 퍼진다** — 참여 결과물이 곧 SNS 콘텐츠가 되도록 설계

## 2. 세계관 & 동선 설계 — "레벨업 미션 투어"

행사장 전체를 하나의 게임판으로 만듭니다. 입장 시 **'독서 레벨 여권(패스포트)'**을 발급받고,
5개 존의 미션을 깨며 레벨업 → 최종 보상으로 이어지는 구조입니다.

```
 [입장/여권 발급]
        │
 ┌──────┼──────────────────────────────┐
 │      ▼                              │
 │  ZONE 1. 트리 광장 (메인 조형·점등식)     │
 │  ZONE 2. 북적북적 마켓 (교환·플리마켓)    │
 │  ZONE 3. 북 아뜰리에 (DIY 체험)          │
 │  ZONE 4. 스테이지 (책터뷰·버스킹·퀴즈쇼)  │
 │  ZONE 5. 시크릿 서재 (AI·심리·포토)      │
 └──────┬──────────────────────────────┘
        ▼
 [리워드 센터 — 레벨별 보상 수령 / 랭킹 보드]
```

**레벨 시스템**
| 레벨 | 조건 | 보상 |
|---|---|---|
| Lv.1 새싹 | 존 미션 2개 완료 | 한정판 스티커팩 (폰꾸·다꾸용) |
| Lv.2 가지 | 존 미션 4개 완료 | 인생네컷 촬영권 or 음료 쿠폰 |
| Lv.3 만개 | 전 존 미션 + 북트리 책 1권 쌓기 | **한정판 굿즈** (북트리 키링/독서등) + 랭킹 보드 등재 |

> 미션 인증은 QR 모바일 스탬프로 처리 — 대기줄 없이 빠르게, 실시간 참여 현황을 스테이지 스크린에 랭킹으로 노출해 경쟁 재미를 더합니다.

## 3. 존(Zone)별 프로그램 상세

### ZONE 1. 트리 광장 — 《자라나는 북트리》 (협동·상징)
행사의 심장. 청소년들이 가져온 기부 도서로 **대형 북트리 조형물을 함께 완성**합니다.

- **한 줄 평 오너먼트**: 책을 쌓을 때 '또래에게 전하는 한 줄 추천사' 태그를 달아 트리를 장식. 태그는 야광 소재로 제작해 점등식 때 함께 빛나도록.
- **실시간 성장 중계**: 트리 옆 전광판에 "현재 1,247권 — 목표까지 253권!" 카운터 노출. 목표 달성 순간을 전원 카운트다운 이벤트로.
- **🌟 점등식 (19:30)**: LED 점등 + 드론/조명 연출 + 참여자 전원 카운트다운. **행사 전체의 인증샷 피크 타임**으로 설계.
- **엔딩 스토리**: 행사 후 트리의 모든 책은 지역 아동센터·도서 소외 지역에 **참여 청소년 전원의 이름으로 기부**. 기부 증서를 참가자에게 모바일로 발송해 "내가 한 일"로 남깁니다.

### ZONE 2. 북적북적 마켓 — 교환·거래·수다 (소통)
- **책 블라인드 데이트**: 감명 깊게 읽은 책을 포장하고 키워드 3개만 적어 1:1 교환. 교환 상대와 '왜 이 책인지' 3분 토크 미션까지 완료하면 스탬프 지급. (의외의 취향 발견 + 자연스러운 또래 교류)
- **십대 플리마켓**: 청소년 셀러를 사전 모집해 중고 책·자작 굿즈·독서 소품을 직접 판매. '내 부스 운영' 경험 자체가 진로 체험이 됩니다.
- **밸런스 게임 벽**: "결말 스포 당하기 vs 300페이지 대기" 같은 책 밸런스 게임 투표벽. 스티커로 투표 — 지나가다 3초 만에 참여 가능한 저비용·고참여 장치.

### ZONE 3. 북 아뜰리에 — DIY 체험 (문화·감각)
| 부스 | 내용 | 포인트 |
|---|---|---|
| **북향(Book Scent) 조향** | 좋아하는 장르(추리·로맨스·판타지)의 무드로 나만의 디퓨저/룸스프레이 조향 | 완성품 = 집에 가져가는 굿즈 |
| **커스텀 북커버·다꾸 랩** | 패브릭·가죽·드로잉으로 나만의 북커버/다이어리 꾸미기 | 다꾸·폰꾸 트렌드 직결 |
| **금박 필사 스튜디오** | 좋아하는 책 속 문장을 엽서에 필사 + 금박 스탬핑 마감 | '텍스트힙' 감성 인증샷 유발 |
| **활판 인쇄 체험** | 레트로 활판으로 내 이름·문장 카드 찍기 | 희소 체험 = 줄 서는 부스 |

### ZONE 4. 스테이지 — 보는 게 아니라 올라가는 무대
- **10대들의 '책터뷰'**: '나를 바꾼 한 권' 또는 '최애 캐릭터 변론'을 주제로 한 5분 스피치 배틀. 관객 투표로 '올해의 책터뷰어' 선정 + 시상.
- **북 골든벨 퀴즈쇼 (17:00)**: 베스트셀러·웹소설·웹툰 원작까지 아우르는 퀴즈 서바이벌. 최후 생존자에게 e북 리더기급 메인 경품. **경품 공개를 사전 홍보의 핵심 떡밥으로 활용.**
- **시크릿 게스트 토크 (18:30)**: 북튜버·웹소설 작가·힙합 아티스트(가사=글쓰기 연결) 등 청소년 인지도 있는 게스트 1팀. **당일까지 실루엣만 공개**해 기대감을 SNS 화제로 전환.
- **점등식 전 어쿠스틱 버스킹 (19:00)**: 지역 청소년 밴드·버스킹팀 무대로 야간 체류 시간 연장.

### ZONE 5. 시크릿 서재 — AI·심리·포토 (힐링·인증)
- **AI 문장 테라피**: 고민 키워드를 입력하면 AI가 위로가 되는 책 속 구절을 **감성 영수증**으로 출력. 영수증 자체가 인증샷 아이템.
- **독서 유형 테스트 (책BTI)**: 12문항 테스트로 '나의 독서 유형 카드' 발급 → 유형별 추천 도서 3권 연결. 유형 카드 공유 = 자발적 SNS 확산 장치.
- **북트리 인생네컷**: 책장·북트리 배경의 셀프 포토부스. 프레임에 행사 로고·날짜 삽입 — **찍는 순간 홍보물이 되는 구조.**

## 5. 청소년 유입 전략 — "오게 만들고, 퍼지게 만든다"

### ① 사전 붐업 (D-30 ~ D-1)
- **숏폼 챌린지**: "내 인생책 3초 소개" 릴스/쇼츠/틱톡 챌린지. 우수작에 행사 VIP 패스(대기 프리패스) 증정.
- **시크릿 게스트 실루엣 티저**: 주 1회 힌트 공개로 추측 댓글 유도.
- **학교 연계**: 인근 중·고 도서부·학생회에 '단체 미션단' 사전 등록 → 단체 참가 학교에 학급문고 지원. (봉사시간 인정 연계 검토)
- **얼리버드 특전**: 사전 신청자 선착순 한정 굿즈 예약권.

### ② 현장 확산 장치
- 전 존 포토 포인트 + 프레임에 행사 해시태그 각인
- 인증샷 SNS 업로드 시 즉석 캡슐 뽑기 1회 (꽝 없음)
- 실시간 랭킹 보드 — 친구 소환("너도 와서 같이 깨자") 유발

### ③ 청소년 크루 '페이지터너(Page Turner)' 운영
- 기획 단계부터 청소년 서포터즈 20~30명 모집
- 담당: 홍보 콘텐츠(릴스·쇼츠) 제작 / 부스 운영 / 무대 진행 보조 / 현장 스케치
- 활동 인증서 + 봉사시간 + 크루 전용 굿즈 지급 → **"운영해 본 경험"이 최고의 리워드**

## 6. 리워드 & 굿즈 설계

| 구분 | 품목(안) | 비고 |
|---|---|---|
| 참여형 | 한정판 스티커팩, 야광 오너먼트 태그 | 저단가·대량 |
| 레벨 보상 | 인생네컷 촬영권, 음료 쿠폰 | 현장 제휴로 비용 절감 |
| 완주 보상 | 북트리 키링, 미니 독서등 | **"여기서만 구할 수 있는" 한정판 강조** |
| 메인 경품 | e북 리더기, 문화상품권 | 골든벨·챌린지 시상용 |

> 굿즈는 '예쁜 것'보다 **'한정판인 것'**이 핵심. 수량 한정 공지가 오전 유입을 만듭니다.

## 7. 운영·안전 계획 (요약)
