# Writer — 처음부터 사람처럼 쓰기

다 쓰고 나서 AI 티를 지우는 것보다, 쓰는 단계부터 사람의 습관으로 쓰는 게 낫다. 이 스킬은 작성 → 셀프 검수 → 완성을 한 번에 처리한다.

## 1. 쓰기 전에 확인

목적(설득/정보/재미), 독자(누가 읽나), 채널(어디 올라가나), 분량. 사용자가 안 줬으면 요청 맥락에서 합리적으로 추정하고, 추정한 내용을 결과물 앞에 한 줄로 밝힌다. 추정이 크게 갈리는 경우에만 물어본다.

문체 프로필(`../sound-like-me/style-profile.md`)이 존재하면 읽고 그 목소리로 쓴다.

## 2. 사람의 습관으로 쓰기

- **구체에서 시작한다.** "많은 사람들이 ~를 고민합니다" 같은 일반론 서두 금지. 장면, 숫자, 사례, 질문 중 하나로 연다.
- **문장 리듬을 일부러 흐트러뜨린다.** 짧은 문장 옆에 긴 문장. 3항목 나열이 나오면 하나를 빼거나 하나를 더한다.
- **주장에는 이유를, 수식어에는 근거를.** "혁신적인 서비스" 대신 뭐가 어떻게 다른지 한 문장.
- **입장을 정한다.** 양쪽을 다 소개하고 끝내지 않는다. 글쓴이의 판단이 담겨야 사람 글이다.
- **짧은 글은 요약 없이 끝낸다.** "결론적으로" 문단은 1,500자 이상 글에만 허용.

## 3. 셀프 검수 (건너뛰지 않는다)

초안 완성 후, 글 언어에 맞게 `../humanizer/references/ai-isms-ko.md` 또는 `ai-isms-en.md`를 기준으로 자기 글을 검사한다:

1. 부정 대구법("단순한 X가 아니라 Y") — 발견 즉시 제거
2. 거창한 선언, 명사화 조언("~하는 것이 중요합니다") — 제거
3. 상투어(혁신적인, robust, delve 류) — 구체적 표현으로 교체
4. 문단마다 같은 리듬 반복 — 한 군데 이상 리듬을 깬다
5. 이모지·볼드 남발 — 강조를 절반으로 줄인다

검수에서 3개 이상 걸리면 해당 문단을 다시 쓴다. 사용자에게는 최종본만 보여주되, 검수에서 뭘 고쳤는지 한 줄로 언급한다.

## 출력 형식

```
(추정한 목적/독자/채널 — 한 줄, 사용자가 명시했으면 생략)

## 완성 글
(본문)

검수 메모: (셀프 검수에서 고친 것 한 줄)
```
