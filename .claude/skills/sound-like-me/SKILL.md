# Sound Like Me — 내 목소리로 쓰기

AI 티를 지우는 것만으로는 부족하다. "AI 같지 않은 글"과 "내가 쓴 글"은 다르다. 이 스킬은 사용자의 실제 글에서 문체를 추출해 재사용한다.

## 모드 판단

- `style-profile.md`가 이 스킬 폴더에 **없으면** → 분석 모드부터
- **있으면** → 적용 모드로 바로 (단, 사용자가 "다시 분석해줘"라고 하면 갱신)
- 사용자가 **말로 녹음한 받아쓰기 원고**(음성 메모, 구글 문서 음성 입력, 클로바노트 등)를 주면 → 프로필 유무와 상관없이 받아쓰기 모드

## 받아쓰기 모드

흉내 낸 문체보다 본인이 실제로 한 말이 더 본인 같다. 이 모드는 새로 쓰지 않고, 받아쓰기에서 잘라내고 순서를 바꿔 글을 만든다.

1. 원고를 정리하지 말고 그대로 받는다. 분량 기준: 완성 글 1,000자당 말하기 약 5~7분 분량. 모자라면 어느 부분을 더 말해 달라고 구체적으로 요청한다.
2. 먼저 구조만 제안한다: 제목 후보, 문단 순서, 각 문단에 쓸 원고 구간. 사용자가 확인하면 진행한다.
3. 원고 문장을 그대로 쓴다. 허용되는 손질은 여기까지:
   - 군말 삭제("어", "그니까", "뭐지"), 말하다 끊긴 문장 정리, 반복 삭제
   - 조사·어미 최소 수정 (구어 "~거든요"는 살린다)
   - 받아쓰기 오류 수정 (고유명사 등. 확실하지 않으면 `[확인: ○○?]` 표시)
4. 새로 쓰는 문장은 **여덟 문장에 하나 이하**로, 문단 연결과 제목에만 쓴다. 내용 문단을 통째로 새로 쓰지 않는다.
5. 새로 쓴 문장은 `〔 〕`로 감싸 표시한다. 완성 글과 받아쓰기를 파일로 저장한 뒤 비율을 **눈대중하지 말고 스크립트로 잰다**:
   ```
   python3 .claude/skills/sound-like-me/scripts/trace_ko.py 완성글.md 받아쓰기.txt
   ```
   결과의 "내 말 비율"을 그대로 적고, "작성"으로 나온 문장 목록을 보여주며 본인 말로 다시 해 달라고 요청한다. 스크립트를 돌릴 수 없는 환경이면 "추정치"라고 밝힌다.
   - 85% 기준은 voiceprint가 영어 글 1편을 영어 탐지기(Pangram) 하나로 측정해 정한 값이다. 한국어에서 AI 탐지 결과와 맞는지는 확인되지 않았다. "85%를 넘으면 탐지기를 통과한다"고 말하지 않는다. 이 기준은 "대부분이 내 말"이라는 작업 목표로만 쓴다.
6. 완성 후 humanizer를 돌리지 않는다. 본인 말을 AI가 다시 다듬으면 이 모드를 쓴 의미가 없다. 사용자가 원하면 red-pen으로 짚기만 한다.
7. 녹음 원본과 받아쓰기 원고는 버리지 말고 보관하라고 한 줄 안내한다. 본인이 쓴 글이라는 가장 확실한 증거다.

## 분석 모드

1. 사용자에게 본인이 쓴 글 샘플을 요청한다. 최소 2편, 합쳐서 500자 이상이면 시작할 수 있다. 채널이 다른 샘플(인스타 캡션 + 블로그 글)이면 채널별 차이도 기록한다.
2. 다음 항목을 관찰해서 `style-profile.md`로 저장한다:
   - **종결어미**: 해요체/합니다체/반말, 문장 끝 습관 ("~거든요", "~잖아요", "~함")
   - **문장 길이 리듬**: 짧은 문장 위주인지, 길게 이어 쓰는지, 섞는지
   - **어휘 온도**: 격식어 vs 구어, 자주 쓰는 단어와 절대 안 쓸 것 같은 단어
   - **유머와 감정 표현**: 자기 비하, 과장, 드립, 감탄사 사용 여부와 빈도
   - **이모지·문장부호**: 이모지 빈도와 종류, "ㅋㅋ", "...", "!!" 같은 습관
   - **글 구조**: 서두를 어떻게 여는지, 결론을 내는지 흐지부지 끝내는지
   - **시그니처 표현**: 이 사람만 쓰는 말버릇 3~5개 (실제 인용으로)
3. 프로필은 관찰이지 규칙이 아니다. "이모지를 문장당 1개 쓴다" 같은 기계적 규칙 대신 "강조하고 싶은 문장 끝에만 가끔 쓴다. 예: ..." 처럼 맥락과 실제 예문을 남긴다.

## 적용 모드

1. `style-profile.md`를 읽는다.
2. 요청받은 글을 쓰거나 고칠 때 프로필의 목소리를 입힌다. 시그니처 표현은 자연스러운 자리에 한두 개만 — 말버릇을 문단마다 넣으면 성대모사가 된다.
3. 완성 후 스스로 검증: "이 글을 본인 계정에 올렸을 때 아는 사람이 위화감을 느낄까?" 느낄 것 같은 문장은 고친다.
4. 출력 끝에 프로필의 어떤 특징을 반영했는지 2~3줄로 밝힌다.

## 주의

- 샘플이 부족한 상태에서 추측으로 프로필을 만들지 않는다. 부족하면 부족하다고 말하고 더 요청한다.
- 프로필은 본인 글쓰기 보조용이다. 타인의 문체를 흉내 내 그 사람인 척하는 용도(사칭)로는 사용하지 않는다.
