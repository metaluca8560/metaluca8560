# Sound Like Me — 내 목소리로 쓰기

AI 티를 지우는 것만으로는 부족하다. "AI 같지 않은 글"과 "내가 쓴 글"은 다르다. 이 스킬은 사용자의 실제 글에서 문체를 추출해 재사용한다.

## 모드 판단

- `style-profile.md`가 이 스킬 폴더에 **없으면** → 분석 모드부터
- **있으면** → 적용 모드로 바로 (단, 사용자가 "다시 분석해줘"라고 하면 갱신)

## 분석 모드

1. 사용자에게 본인이 쓴 글 샘플을 요청한다. 최소 2편, 합쳐서 500자 이상이면 시작할 수 있다. 채널이 다른 샘플(인스타 캡션 + 블로그 글)이면 채널별 차이도 기록한다.
2. 다음 항목을 관찰해서 `style-profile.md`로 저장한다:
   - **종결어미**: 해요체/합니다체/반말, 문장 끝 습관 ("~거든요", "~잖아요", "~함")
   - **문장 길이 리듬**: 짧은 문장 위주인지, 길게 이어 쓰는지, 섞는지
   - **어휘 온도**: 격식어 vs 구어, 자주 쓰는 단어와 절대 안 쓸 것 같은 단어
   - **유머와 감정 표현**: 자기 비하, 과장, 드립, 감탄사 사용 여부와 빈도
   - **이모지·문장부호**: 이모지 빈도와 종류, "ㅋㅋ", "...", "!!" 같은 습관
   - **글 구조**: 서두를 어떻게 여는지, 결론을 내는지 흐지부지 끝내는지
   - **시그니처 표현**: 이 사람만 쓰는 말버릇 3~5개 (실제 인용으로)
3. 프로필은 관찰이지 규칙이 아니다. "이모지를 문장당 1개 쓴다" 같은 기계적 규칙 대신 "강조하고 싶은 문장 끝에만 가끔 쓴다. 예: ..." 처럼 맥락과 실제 예문을 남긴다.

## 적용 모드

1. `style-profile.md`를 읽는다.
2. 요청받은 글을 쓰거나 고칠 때 프로필의 목소리를 입힌다. 시그니처 표현은 자연스러운 자리에 한두 개만 — 말버릇을 문단마다 넣으면 성대모사가 된다.
3. 완성 후 스스로 검증: "이 글을 본인 계정에 올렸을 때 아는 사람이 위화감을 느낄까?" 느낄 것 같은 문장은 고친다.
4. 출력 끝에 프로필의 어떤 특징을 반영했는지 2~3줄로 밝힌다.

## 주의

- 샘플이 부족한 상태에서 추측으로 프로필을 만들지 않는다. 부족하면 부족하다고 말하고 더 요청한다.
- 프로필은 본인 글쓰기 보조용이다. 타인의 문체를 흉내 내 그 사람인 척하는 용도(사칭)로는 사용하지 않는다.
