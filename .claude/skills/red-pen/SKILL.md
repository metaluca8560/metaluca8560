# Red Pen — 고치지 않고 짚기만

글쓴이가 직접 고칠 수 있도록 문제 지점만 표시한다. 대신 써주지 않는 이유: 글쓴이의 목소리를 지키는 가장 확실한 방법은 글쓴이가 직접 고치는 것이다.

## 작업 순서

1. 글이 한국어면 `../humanizer/references/ai-isms-ko.md`, 영어면 `../humanizer/references/ai-isms-en.md`를 읽는다 (AI 티 판별 기준으로 사용).
2. 글 전체를 읽고 문제 지점을 찾는다. AI 티 패턴뿐 아니라 일반적인 글쓰기 문제도 본다:
   - 하나 마나 한 문장 (지워도 글이 안 무너지는 문장)
   - 근거 없는 주장, 두루뭉술한 수식어
   - 같은 말 반복, 문단 간 논리 비약
   - 첫 문장이 약해서 독자를 못 붙잡는 경우
3. 지적은 **많아야 7개**. 전부 빨간펜 치면 글쓴이는 아무것도 못 고친다. 가장 아픈 곳부터 우선순위로 고른다.

## 출력 형식

각 지적은 이 형태로:

```
🔴 "원문 문장 인용"
문제: 한 줄 진단
방향: 어떻게 고치면 되는지 힌트 (완성 문장은 주지 않는다)
```

마지막에 점수표와 두 줄 총평을 붙인다.

```
| 항목 | 점수 | 한 줄 근거 |
|---|---|---|
| 직접성 | /10 | 할 말을 바로 하는가, 예고·서론으로 돌아가는가 |
| 리듬 | /10 | 문장 길이와 문단 끝맺음이 섞여 있는가, 박자가 일정한가 |
| 독자 신뢰 | /10 | 독자가 알아들을 걸 믿는가, 같은 말을 풀어 반복하는가 |
| 진정성 | /10 | 사람이 쓴 것처럼 들리는가, AI 티 패턴이 겹치는가 |
| 밀도 | /10 | 지워도 되는 문장이 없는가 |
| 합계 | /50 | |
```

- 35점 미만이면 총평 첫 줄에 "다시 손볼 글"이라고 밝힌다. 35점 이상이면 지적은 다듬기 수준이라고 알린다.
- 점수는 위 지적과 맞아야 한다. 진정성에서 깎았으면 그 근거가 된 🔴 지적이 위에 있어야 한다.
- 채널 성격은 감안한다. 인스타 캡션의 짧은 문장 연타는 리듬 감점이 아니다.

총평 두 줄: 이 글의 가장 큰 강점 하나, 가장 먼저 고칠 것 하나.

## 주의

- 고쳐 쓴 완성 문장을 제시하지 않는다. "이렇게 바꾸세요"가 아니라 "이 방향으로 가면 됩니다"까지만. 사용자가 "그냥 고쳐줘"라고 하면 humanizer로 전환한다.
- 취향 지적과 결함 지적을 구분한다. 취향이면 "취향 차이지만"이라고 밝힌다.
- 잘 쓴 문장 하나는 꼭 언급한다. 뭘 잘했는지 알아야 그 감각을 반복할 수 있다.
