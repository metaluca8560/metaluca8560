# English AI-ism Pattern Reference

Patterns that mark English text as AI-generated. Word swaps alone don't fix AI-sounding text — the structural habits (sections 2–3) are the stronger tells. Diagnose first, then rewrite the sentence around what it actually means.

## 1. Overused words

| AI word | Human alternative direction |
|---|---|
| delve (into) | look at, dig into, get into |
| crucial, pivotal | important — or better, say *why* it matters |
| tapestry, landscape, realm | drop the metaphor; name the actual thing |
| foundational | basic, core |
| robust, seamless | say what it actually does well |
| leverage, utilize | use |
| foster, facilitate | help, make easier |
| comprehensive, holistic | complete — or list what's covered |
| streamline, optimize | specific verb: cut, merge, speed up |
| moreover, furthermore | also, and — or just start the sentence |
| It's worth noting that | (delete; just say the thing) |
| In today's fast-paced world | (delete the entire opener) |

## 2. Structural tells (stronger signals than words)

**Negative parallelism — "It's not X, it's Y"**
- ❌ This isn't just a tool. It's a way of thinking.
- ✅ The tool changes how you think about the problem.
- One instance is enough to raise suspicion. Remove every one.

**The grand pronouncement**
- ❌ This isn't a budget. It's a statement of intent.
- ✅ The budget reflects three priorities: ...
- Dramatic redefinition belongs in ad copy, nowhere else.

**Adverb abuse — "X quietly runs Y"**
- ❌ The script quietly handles retries. / She effortlessly manages three teams.
- ✅ The script retries failed calls up to three times.
- Cinematic adverbs (quietly, effortlessly, seamlessly, gracefully) narrate instead of inform.

**Rule of three everywhere**
- "clear, concise, and compelling" — when every list has exactly three items, the rhythm gives it away. Vary: sometimes one, sometimes five.

**Em-dash chains and balanced clauses**
- "Not only X — but also Y" in every paragraph. Humans write lopsided sentences.

**Summary paragraphs on short texts**
- "In conclusion," on a 300-word piece. Short texts just end.

## 3. Tone tells

- **Both-sidesing everything**: "On one hand... on the other hand..." — if you have a view, state it.
- **Hedging stacks**: "It could potentially be argued that..." — one hedge max.
- **Empty enthusiasm**: "Great question!", "Hope this helps!" — delete.
- **Over-signposting**: "Let's explore...", "Now let's turn to..." — just turn to it.
- **Bold-word confetti**: bolding every key term. Bold one thing per section, or nothing.

## 4. Judgment call

Humans use these words too. Flag text as AI-ish when **three or more signals stack**, and fix the structural tells (negative parallelism, pronouncements, adverb narration) before touching individual words.
