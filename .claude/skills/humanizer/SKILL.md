# Humanizer — AI 티 제거

글의 의미와 사실은 그대로 두고, AI 특유의 단어·문장 구조·톤 습관만 제거해서 사람이 쓴 글처럼 만든다.

## 작업 순서

1. **패턴 사전을 먼저 읽는다.** 글이 한국어면 `references/ai-isms-ko.md`, 영어면 `references/ai-isms-en.md`, 섞여 있으면 둘 다 읽는다.
2. **진단부터 한다.** 원문에서 발견한 패턴을 나열한다. 신호가 2개 이하면 "이미 충분히 자연스럽다"고 알리고 미세 수정만 한다 — 멀쩡한 글을 억지로 고치면 오히려 어색해진다.
3. **구조적 신호부터 고친다.** 부정 대구법, 거창한 선언, 명사화된 조언("~하는 것이 중요합니다"), 3항목 반복 리듬이 단어 치환보다 우선이다. 단어만 바꾸면 골격이 그대로라 여전히 티가 난다.
4. **문체는 보존한다.** 해요체는 해요체로, 합니다체는 합니다체로, 반말은 반말로. 글쓴이의 유머, 이모지 사용량, 문장 길이 습관도 원문 수준을 유지한다. 다듬는 것이지 다시 쓰는 게 아니다.
5. **사실은 건드리지 않는다.** 숫자, 이름, 날짜, 주장 내용은 그대로. 표현만 바꾼다.

## 출력 형식

```
## 다듬은 글
(전체 결과물)

## 바꾼 것
- "원래 표현" → "바꾼 표현": 한 줄 이유
(주요 변경 3~7개만. 전부 나열하지 않는다)
```

## 주의

- 기계적 치환 금지. "delve"를 "살펴보다"로 전부 바꾸는 식의 일괄 치환은 새로운 부자연스러움을 만든다. 문장마다 문맥에 맞는 표현을 고른다.
- 길이는 원문의 ±20% 이내. 다듬는다는 핑계로 내용을 늘리거나 요약하지 않는다.
- 과잉 교정 경계. 사람 글에도 "~를 통해"나 "robust"는 나온다. 신호가 겹칠 때만 고친다.
