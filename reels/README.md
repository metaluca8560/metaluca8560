# 릴스 커버 이미지

`script.js`의 `REELS` 배열이 여기 파일을 가리킵니다.
파일명은 **릴스 코드와 똑같이** 맞춰야 합니다.

| 파일명 | 릴스 | 제목 |
|--------|------|------|
| `DcDz9ekSfID.jpg` | instagram.com/reel/DcDz9ekSfID | 비개발자의 역습 |
| `DcL5RkDyVat.jpg` | instagram.com/reel/DcL5RkDyVat | 토스 미니앱 14개 출시 |
| `Dcn4YmLyhFG.jpg` | instagram.com/reel/Dcn4YmLyhFG | 명함 공모전 |

## 규격

- **비율** — 3:4 (세로). 카드가 3:4라 이 비율이면 안 잘립니다.
- **크기** — 가로 900px 정도면 충분합니다. 카드가 화면에서 최대 260px로 보이고,
  고해상도 화면(2배)을 감안해도 520px면 됩니다.
- **형식** — JPG. 품질 80 정도로 저장하면 한 장에 60~100KB로 떨어집니다.
- **용량** — 한 장 150KB를 넘기지 마세요. 세 장이면 방문자가 다 받습니다.

## 없어도 됩니다

파일이 없거나 깨지면 브랜드 그라데이션 카드로 자동 대체됩니다.
그래서 일부만 넣어도 화면이 깨지지 않습니다.

## 릴스를 추가할 때

`script.js`의 `REELS`에 한 줄 넣고, 여기에 같은 이름의 이미지를 두면 됩니다.

```js
{ code: "새릴스코드", title: "제목", thumb: "reels/새릴스코드.jpg" },
```
