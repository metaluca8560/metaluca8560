# 오늘 어디 아파? 🩺 — 증상 안내 & 병원 찾기 (MVP)

어디가 아플 때 **대화하며 어느 과에 가야 할지·얼마나 급한지**를 안내하고,
**가까운 병원·약국·응급실**을 찾아주는 길잡이 웹앱. 순수 HTML/CSS/JS, 빌드 불필요.

> ⚠️ **이 앱은 진단이 아니라 참고용 안내입니다.** 정확한 진단은 의사와 상담하세요. 위급 시 119.

## 핵심 원칙
- **진단(❌) → 안내·triage(⭕)**: "○○병입니다" 대신 "○○과 진료를 권해요 / 응급도 / 갈 곳"
- **레드플래그 우선**: 위험 신호 선택 시 무조건 "즉시 119/응급실"
- **개인 건강정보는 서버 저장 없음** (기기 내 처리)

## 기능 (v1)
- ⒜ **증상 문진** — 부위 → 열 → 정도 → 기간 → 위험신호 5단계, 룰 기반으로 **의심 진료과 + 응급도(🟢🟡🔴)** 안내
- ⒝ **주변 찾기** — 위치 기반 지도 검색(병원/약국/응급실), 공식 서비스(E-Gen·심평원) 링크. **API 키 불필요**
- ⒞ **아이(소아) 모드** — 소아청소년과 우선, 소아 전용 위험신호(탈수·영아 발열), 달빛어린이병원 안내
- ⒟ **빠른 응급처치 (17종)** — 목 막힘/질식·하임리히, 벌 쏘임, 벌레·진드기, 화상, 출혈, 코피, 염좌, 눈 이물질, 실신, 열사병, 저체온증, 동물 물림, 식중독, 약·세제 삼킴(중독), 감전, 치아 빠짐 등. 검색 + 아코디언, "하지 마세요"·"즉시 119" 표기. `app.js`의 `FIRST_AID` 배열에서 추가/수정
- **3가지 모드**: 어르신(큰 글씨·기본) / 일반 / 아이

## 구성
| 파일 | 설명 |
|------|------|
| `index.html` | 상단(모드 전환) · 면책 배너 · 문진 · 결과 · 주변 찾기 · 응급 전화 · 푸터 |
| `styles.css` | 시니어 친화(큰 글씨·큰 버튼·고대비) 테마. 모드별 글자 크기 변수 |
| `app.js` | 문진 단계 머신 + 룰 기반 판단(`decide()`) + 레드플래그 + 위치기반 찾기 |

## 안전 로직 (꼭 유지)
`app.js`의 `RED_FLAGS` / `RED_FLAGS_CHILD`는 **가드레일**입니다. 하나라도 선택되면
점수와 무관하게 응급(🔴)으로 안내합니다. AI 버전으로 바꿔도 이 가드레일은 유지하세요.

## 2단계 업그레이드 (AI 문진)
`app.js`의 `decide()`(룰 기반)를 **Claude API 호출**로 교체하면 AI가 자연스럽게 문진합니다.
- 정적 사이트라 API 키 노출 방지를 위해 **가벼운 서버리스 함수**(예: Cloudflare Workers/Vercel Function)를 두고 그 뒤에서 Claude API 호출 권장
- 모델은 최신 Claude 사용, 응답에 **레드플래그 가드레일**을 시스템 프롬프트로 강제

## 데이터(실서비스용)
주변 찾기를 실시간 공공데이터로 바꾸려면 [공공데이터포털](https://www.data.go.kr)의
- 전국 병의원/약국 정보, **응급의료기관 정보(E-Gen)**, 약국 정보 API에
서비스 키를 발급받아 연결하세요. (MVP는 지도 검색 + 공식 포털 링크로 대체)

## 실행

python3 -m http.server 8000   # http://localhost:8000/medi/
